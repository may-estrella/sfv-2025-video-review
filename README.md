# SFV 2025 映像素材レビュー

2025年撮影の693本について、各動画から抽出した4枚の代表フレームを検索できます。

公開ページ： https://may-estrella.github.io/sfv-2025-video-review/

- `index.html`：検索ページ
- `catalog.csv`：公開用の一覧
- `contact_sheets/`：693枚のコンタクトシート

元動画・PC内のファイルパス・未確定の企業名は掲載していません。地域は撮影フォルダ名、映像テーマと候補ランクは代表フレームからの一次判定です。音の内容、連続した動き、9:16への適性は未確認です。
